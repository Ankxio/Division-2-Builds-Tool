Your own item pictures go in this folder.

Name each file after the item, for example:

  Eagle Bearer.png
  Striker's Battlegear.png          (used for every piece of the set)
  Striker's Battlegear-chest.png    (used for the chest only)
  Assault Turret.png                (skills use the variant followed by the skill)

PNG, JPG, WEBP, AVIF and SVG all work. Square pictures suit gear and skills; wide ones
(about 3:1) suit weapons. Then run tools\update-images.ps1 so the site knows which
pictures exist, and upload the img folder.

Only use pictures you are allowed to publish (your own screenshots, for example).
